Installation et configuration

Retrouvez toutes les informations nécessaires pour configurer Focus Autosplitter.

🚀 Installation de Focus Autosplitter

1. Télécharger Focus Autosplitter

Téléchargez la dernière version depuis la page téléchargement.

Lancez ensuite :

Focus-Autosplitter-Setup.exe

Suivez les étapes d'installation puis lancez le logiciel.

2. Installer LiveSplit

Focus Autosplitter utilise LiveSplit pour gérer votre timer.

⏱ Télécharger LiveSplit

1. Téléchargez l'archive ZIP.

2. Extrayez son contenu dans un dossier.

3. Lancez :

LiveSplit.exe

💡 LiveSplit est portable, aucune installation Windows n'est nécessaire.

3. Activer LiveSplit Server

Les versions récentes de LiveSplit intègrent déjà LiveSplit Server. Aucun téléchargement supplémentaire n'est nécessaire.

Pour l'activer :

  1. Ouvrez LiveSplit.
  2. Faites un clic droit sur le timer.
  3. Cliquez sur Control.
  4. Cliquez sur Start TCP Server.

Le port utilisé est :

16834

4. Connecter Focus Autosplitter

  1. Lancez Focus Autosplitter.
  2. Ouvrez les paramètres.
  3. Vérifiez le port LiveSplit.
16834

Cliquez ensuite sur le bouton connexion.

🟢 LiveSplit : Connecté

❓ Questions fréquentes

Le jeu n'est pas détecté

Vérifiez que la bonne fenêtre est sélectionnée.

LiveSplit reste déconnecté

Vérifiez que Start TCP Server est activé et que le port est 16834.

L'aperçu est noir

Essayez de relancer le jeu ou Focus Autosplitter.
