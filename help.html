🚀 Installation de Focus Autosplitter

1. Télécharger Focus Autosplitter

Téléchargez la dernière version depuis la page Téléchargement.

Lancez ensuite :

Focus-Autosplitter-Setup.exe

Suivez les étapes de l'installation puis lancez le logiciel.

2. Installer LiveSplit

Focus Autosplitter nécessite LiveSplit pour fonctionner.

Téléchargez la dernière version officielle :

⏱ Télécharger LiveSplit

1. Téléchargez l'archive ZIP.

2. Extrayez son contenu dans le dossier de votre choix.

3. Lancez :

LiveSplit.exe

💡 LiveSplit est portable : aucune installation Windows n'est nécessaire.

3. Activer LiveSplit Server

Les versions récentes de LiveSplit intègrent déjà LiveSplit Server. Aucun téléchargement supplémentaire n'est nécessaire.

Pour l'activer :

  1. Ouvrez LiveSplit.
  2. Faites un clic droit sur le timer.
  3. Allez dans Control.
  4. Cliquez sur Start TCP Server.

Le serveur utilise par défaut le port :

16834

4. Connecter Focus Autosplitter

  1. Lancez Focus Autosplitter.
  2. Ouvrez les paramètres.
  3. Vérifiez que le port LiveSplit est :
16834

Cliquez ensuite sur :

Le statut doit passer en :

🟢 LiveSplit : Connecté

✅ Vérification finale

  • Focus Autosplitter est ouvert.
  • LiveSplit est ouvert.
  • Start TCP Server est activé.
  • Le statut affiche Connecté.
  • Votre jeu est sélectionné.
